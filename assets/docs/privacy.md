# BIT Code Quest 隱私權說明

最後更新：2026-11-11

- **不收集個人資料**：遊戲不需要帳號，不會要求姓名、電子郵件或位置。
- **進度只存在你的裝置上**：關卡進度、星星、成就、造型和設定都存在這台裝置的本機儲存空間，不會上傳。在「設定」按「重設遊戲進度」，或刪除 App，就會一併刪除。
- **沒有廣告和追蹤**：不使用廣告、分析或追蹤工具。
- **分享由家長決定**：只有在按下「分享」、並由家長答對一題乘法之後，才會把成績、學習證書或關卡的文字交給你選的 App（例如訊息或郵件）。
- **朗讀**：任務說明的朗讀使用裝置內建的文字轉語音功能。
- **排行榜**：要按「參加」才會加入每日排行榜。暱稱由遊戲從預設的詞語組合而成（例如「勇敢的小狐狸」），不能自己輸入，所以不會出現真實姓名。隨時可以在排行榜或「設定」按「不參加了」退出。參加後，每次完成每日挑戰會把暱稱、一組隨機產生的玩家代號、當天題目的版本，以及你寫的程式送到排行榜伺服器；伺服器重新執行程式來算成績，只保留最近 14 天。玩家代號只用來讓每位玩家每天只留一筆最好的成績，不會和裝置、帳號或其他資料連結。不會送出其他資料。沒有排行榜伺服器的版本不會顯示排行榜。
- **相機**：只有在「自己出題」裡按「掃描」時才會打開相機，用來讀取關卡 QR code；畫面不會儲存或上傳。不掃描也能用「貼上」載入關卡。
- **其他權限**：遊戲不需要麥克風、聯絡人或位置權限。
- **給兒童使用**：沒有廣告、沒有內購、沒有聊天，也沒有連到網頁的連結。

如果之後要送出更多資料，會先更新這份說明，並在送出前詢問。

# BIT Code Quest Privacy Policy

Last updated: 2026-11-11

- **No personal data**: no account is needed. The game never asks for a name, email address or location.
- **Progress stays on your device**: levels, stars, achievements, looks and settings are stored locally and never uploaded. Tapping Reset game progress in Settings, or deleting the app, deletes them.
- **No ads or tracking**: the game uses no advertising, analytics or tracking tools.
- **A grown-up decides what is shared**: only after tapping Share, and after a grown-up answers a multiplication question, is the text of a score, certificate or level handed to the app you pick.
- **Read aloud**: mission briefs are read by the device's built-in text-to-speech.
- **Leaderboard**: players join the daily leaderboard only by tapping Join. Nicknames are put together by the game from preset words (such as "Brave Fox") and can't be typed, so real names never appear. Players can leave at any time from the leaderboard or Settings. While they are in, each finished daily challenge sends the nickname, a random player code, which version of the day's puzzle it was and the program they wrote to the leaderboard server, which re-runs the program to work out the score and keeps 14 days. The player code only lets each player keep one best score a day; it is not linked to the device, an account or any other data. Nothing else is sent. Builds without a leaderboard server show no leaderboard.
- **Camera**: used only while scanning a level's QR code in the level editor. Images are never stored or uploaded, and pasting a code works without the camera.
- **Other permissions**: the game needs no microphone, contacts or location access.
- **For children**: no ads, no in-app purchases, no chat and no links to websites.

If more data is ever sent, this policy will be updated first and players will be asked before it is sent.

- **シェアはおうちの人が決めます**：「シェア」をおして、おうちの人がかけ算の問題に正しく答えたときだけ、スコア、しょうじょう、ステージのテキストを、あなたがえらんだアプリ（メッセージやメールなど）にわたします。

- **ランキング**：「参加する」をおしたときだけ、デイリーランキングに参加します。ニックネームはゲームが決まった言葉を組み合わせて作るので（たとえば「ゆうかんなキツネ」）、自分で入力できず、本当の名前が出ることはありません。いつでもランキングか「設定」で「やめる」をおして、ぬけられます。参加しているあいだは、デイリーチャレンジをクリアするたびに、ニックネーム、ランダムに作ったプレイヤーコード、その日の問題のバージョン、あなたが書いたプログラムをランキングサーバーに送ります。サーバーはプログラムをもう一度実行してスコアを出し、さいきん14日分だけをのこします。プレイヤーコードは、1人1日1つのベストスコアだけをのこすために使い、デバイス、アカウント、ほかのデータとはむすびつけません。ほかのデータは送りません。ランキングサーバーのないバージョンでは、ランキングは表示されません。
- **カメラ**：「ステージを作る」で「読みとる」をおしたときだけ、ステージの QR コードを読むためにカメラを開きます。うつったものは保存もアップロードもしません。読みとらなくても、「はりつけ」でステージを読みこめます。
- **ほかの許可**：マイク、連絡先、いる場所の許可はいりません。
- **子ども向け**：広告、アプリ内課金、チャット、ウェブサイトへのリンクはありません。

これからもっと多くのデータを送ることになったときは、先にこの説明を新しくして、送る前にたずねます。

# Política de privacidad de BIT Code Quest

Última actualización: 2026-11-11

- **Sin datos personales**: no hace falta ninguna cuenta. El juego nunca pide un nombre, un correo electrónico ni una ubicación.
- **El progreso se queda en tu dispositivo**: los niveles, las estrellas, los logros, los aspectos y los ajustes se guardan en el dispositivo y nunca se suben. Si tocas Reiniciar el progreso en Ajustes, o si borras la app, se eliminan.
- **Sin anuncios ni rastreo**: el juego no usa herramientas de publicidad, analítica ni rastreo.
- **Un adulto decide qué se comparte**: solo después de tocar Compartir, y después de que un adulto responda una pregunta de multiplicar, se entrega el texto de una puntuación, un diploma o un nivel a la app que elijas.
- **Lectura en voz alta**: las misiones se leen con la función de texto a voz integrada en el dispositivo.
- **Clasificación**: los jugadores solo se unen a la clasificación diaria si tocan Unirme. Los apodos los forma el juego a partir de palabras predefinidas (como "Zorro Valiente") y no se pueden escribir, así que nunca aparecen nombres reales. Los jugadores pueden salir en cualquier momento desde la clasificación o desde Ajustes. Mientras participan, cada Desafío diario terminado envía al servidor de la clasificación el apodo, un código de jugador aleatorio, la versión del desafío de ese día y el programa que escribieron. El servidor vuelve a ejecutar el programa para calcular la puntuación y guarda 14 días. El código de jugador solo sirve para que cada jugador conserve una mejor puntuación al día; no está vinculado al dispositivo, a una cuenta ni a ningún otro dato. No se envía nada más. Las versiones sin servidor de clasificación no muestran la clasificación.
- **Cámara**: solo se usa mientras escaneas el código QR de un nivel en el editor de niveles. Las imágenes nunca se guardan ni se suben, y pegar un código funciona sin la cámara.
- **Otros permisos**: el juego no necesita acceso al micrófono, a los contactos ni a la ubicación.
- **Para niños**: sin anuncios, sin compras dentro de la app, sin chat y sin enlaces a sitios web.

Si alguna vez se envían más datos, primero se actualizará esta política y se pedirá permiso a los jugadores antes de enviarlos.
